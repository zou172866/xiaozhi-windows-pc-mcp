# 用小智继续

把当前酒馆单人聊天最近一至三轮文字问答导成文件，在小智控制台预览，再交给指定 ESP32 的酒馆存档。

## 安装

在 SillyTavern 的 `data/<用户目录>/extensions/` 下新建 `xiaozhi-handoff` 文件夹，将本目录的 `manifest.json`、`index.js`、`handoff.js` 放在里面。刷新酒馆页面，打开「扩展」，找到「用小智继续」。[SillyTavern 官方扩展说明](https://docs.sillytavern.app/for-contributors/writing-extensions/)

## 接着聊

1. 在本机通过 localhost 或 HTTPS 打开酒馆，进入一个角色的聊天。如有多个候选回复，选中要继续的那一条。
2. 回复生成完后，在「扩展 → 用小智继续」选择轮数，点「导出对白文件」。`xiaozhi-tavern.json` 中含有对白原文，下载到浏览器的下载目录。
3. 在小智控制台的「对话记忆存档」选中 ESP32，展开「从酒馆接续聊天」并选择文件。核对对白后点「导入并切换到酒馆」，按控制台提示开启新的语音连接。[小智控制台](http://localhost:18080/)

一轮是相邻的一条用户消息和一条角色回复，每条最多 2000 个 Unicode 字符。扩展跳过开场白、系统消息、含文档附件或工具调用的消息，以及尚未获得回复的提问。导出使用当前显示的候选回复。聊天标识由酒馆网址来源、角色头像文件名和聊天文件名计算；改名或切换酒馆地址会生成新的标识。
